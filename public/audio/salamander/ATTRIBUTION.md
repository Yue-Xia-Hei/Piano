# Piano sample attribution

Salamander Grand Piano — Alexander Holm, Yamaha C5 recordings.

https://creativecommons.org/licenses/by/3.0/
Source: https://github.com/Tonejs/audio/tree/master/salamander

These MP3 files are redistributed unchanged from Tonejs/audio. This project
selects the nearest minor-third sample, changes playback rate, and applies
velocity-dependent gain/filtering and release envelopes at runtime. This subset
has one recorded dynamic layer; it does not reproduce the full original library.
